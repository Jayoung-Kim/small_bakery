# 꼬마 빵집

숲속 동물 손님에게 빵을 구워 팔고, 번 동전으로 마을을 꾸미는 1인용 3D 힐링 게임이에요.

- **플레이**: 손님 머리 위 주문을 보고 🔥오븐에서 굽기(타이밍 게임) → 🎨장식대에서 토핑 → 카운터에서 건네기. 단골이 되면 선물을 주고, 더 친해지면 마을로 이사 와요. 레벨이 오르면 새 빵·토핑·손님·꾸미기 물건이 열려요.
- **텃밭**: 오른쪽 텃밭에 밀·딸기·블루베리·호박을 심고 물을 주면 실제 시간이 지나며 자라요(게임을 꺼도 자람). 수확한 재료로 빵을 만들면 동전과 친밀도 보너스가 있어요.
- **내 집**: 왼쪽 집을 눌러 벽·지붕 색을 바꾸고 3단계까지 증축하고, 안에 들어가 가구를 놓을 수 있어요. 이웃이 놀러 오면 텃밭과 집 안도 구경할 수 있어요.
- **알바생**: 🧑‍🍳 버튼에서 빵집(보슬·단추·별이)과 카페(모카·라떼·코코아) 알바를 각각 10분씩 고용하면 주문을 대신 만들어 팔아줘요.
- **방 꾸미기**: 집 안에서 🎨 버튼으로 벽지 7종·바닥 5종을 고르고, 가구 16종을 배치해요.
- **숲속 카페**: Lv.2부터 🪙300으로 빵집 오른쪽에 카페를 열면 손님이 음료도 주문해요. 뒤쪽 바에서 따뜻하게/차갑게를 고르고 꾹 눌러 따르기, 앞쪽 카운터에서 건네기. 텃밭 커피콩·딸기·블루베리·호박을 쓰면 보너스.
- **화면**: 끌거나 두 손가락으로 비틀어 360도 회전(PC는 Q/Z 키), 두 손가락·마우스 휠로 확대/축소, ☰ 버튼으로 메뉴 열고 닫기.
- **조작**: PC는 WASD/방향키 + E/스페이스(R로 꾸미기 물건 돌리기), 휴대폰은 가고 싶은 곳을 눌러서 이동(오븐·장식대·카운터·주민을 누르면 걸어가서 바로 행동). 휠이나 두 손가락으로 확대/축소.
- **저장·이웃**: Supabase 로그인(이메일+비밀번호)으로 계정마다 마을이 저장되고, 🏡이웃 메뉴에서 다른 사람 마을에 놀러 가 하트와 방명록을 남길 수 있어요.
- 앱을 전환하거나 화면을 끄면 바로 저장하고, 기기에도 사본을 남겨서 다음에 더 최신 쪽을 불러와요.

## 구조

- `index.html` 한 파일짜리 정적 사이트예요. Three.js와 supabase-js를 jsDelivr CDN에서 불러와요. 빌드 과정이 없어서 Vercel에서 Framework Preset "Other"로 그대로 배포하면 돼요.
- Supabase 주소와 publishable 키는 `index.html` 위쪽 `SUPABASE_URL`, `SUPABASE_ANON_KEY`에 있어요. 비우면 기기 저장 체험 모드로 돌아가요.
- DB 테이블과 권한(RLS)은 `supabase-setup.sql`에 있어요.
